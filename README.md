# Dolphin

### GameCube and Wii emulator with enhancements

Dolphin is the premier GameCube and Wii emulator, delivering near-perfect accuracy with massive performance improvements over original hardware. Play hundreds of classics at 4K with widescreen, higher frame rates, and online multiplayer.

<br>

---

## Features

| | |
|:---|:---|
| **4K & HD Textures** | Render original games at 4× or higher resolution with texture packs |
| **Online Multiplayer** | Netplay support for games that didn't originally have online features |
| **Save States** | Save and load at any point — perfect for difficult sections |
| **Controller Mapping** | Full support for original GameCube adapters, Wii remotes, and modern pads |
